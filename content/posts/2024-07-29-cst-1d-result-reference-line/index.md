## 引言

CST Studio Suite® 是电磁仿真领域的重要工具，其强大的后处理功能对于深入分析仿真结果至关重要。

而在进行 1D 结果解读时，若能在结果中添加对应的参考线，可以显著提升数据解读的效率。

本文将介绍两种在 CST 中添加参考线的方法，助您更高效地进行仿真分析。

## 方法1：导入 EMC 标准

该方法通过内置的宏脚本选择或导入标准文件。

针对已有且常用的 EMC 测试标准，CST 提供了相应的后处理模板（图1.1）。用户可以在 Post-Processing 功能区中点击 EMC Workflow，选择 EMI Standard Limitied Lines。

## 选择标准

进入 EMI Standard Limitied Lines 后，可以选择对应的 EMC 测试标准（图1.2）。

点击 OK 后，就可以看到对应标准的参考范围（图1.3）。

在左侧的导航树中可以看到，该宏命令在 1D Result 中建立了一个文件夹，并生成了很多描述标准的参考数据文件。

我们可以将仿真结果复制到该文件夹中，然后点击该文件夹以显示文件夹下的所有结果，直观地查看结果是否合规。

## 导入标准/数据

如果列表中没有需要的标准，也可以在 EMI Standard Limitied Lines 这个宏中导入本地的 EMC 测试标准，或者自己根据标准编写参考线（图1.4）。

勾选 User defined standard，就可以激活下面的功能。点击 Load File 导入准备好的数据文件。

文档的格式可以点击右下角的 Example Format 参考（图1.5），可以点击 Copy to clipboard 复制粘贴到文本编辑器中。

导入完毕后，在 Limit Unit 一栏中勾选对应的单位，即可在结果中生成参考线，最终的效果和图1.3类似。

## 方法2：手动编写参考线

该方法通过手动导入外部结果文件到 1D Result 文件夹中，并同时显示多个文件，从而得到参考线。参考线可以根据我们的需要自行编写。

CST 会根据我们导入文件时选择的数据类型，自动匹配合适的绘图类型，并显示在 1D Plot 功能区的 Plot Type 中。

而线性值（linear）与对数值（dB）两种显示方式在导入之后不能直接在 Plot Type 中切换。因此参考线的数据格式在导入前，需要特别留意一下。

## 2a.对比目标为线性值（linear，如VSWR）

本节将演示如何在 VSWR 结果中添加参考线，主要操作可分成三个步骤：

根据参考范围编辑参考线；

将参考线导入到结果中；

选择对应的绘图类型显示结果。

## 定义参考线

例如，我们想要对比的结果为 VSWR（图2.2），在 5.6-5.7 GHz 范围内添加纵轴坐标为 2 的参考线。

通过左上角的 Plot Type 可以看到，该结果的显示类型为线性（linear）。

参考线数据文件的数据的结构非常简单：第一列为横坐标数据，第二列为纵坐标数据，中间可以用空格、Tab或者英文逗号作为分隔符（图2.3）。

## 导入参考线

在导航树的 1D Result 文件夹中新建一个文件夹（例如图2.4中的 compare-VSWR），并将需要对比的原始数据复制到该文件夹中。

随后右键点击该文件夹，选择 Import Result Curve From Ascii File，导入刚才编写的参考线（图2.4）。

在弹窗中选择文件，并在下面的 Data Format 中选择数据类型（图2.5）。

默认勾选的类型是 Real，对于线性（linear）的结果而言，选择 Real 或者 Magnitude 都可以。

随后点击"打开"，完成导入。

## 显示结果

导入完毕后，将导入的结果 Import1 重命名为 VSWR-Reference1。

点击该文件夹以显示文件夹下的所有结果，直观地查看仿真结果是否符合规范（图2.6）。

## 2b.对比目标为对数值（dB，如S参数）

前面提到过，导入 CST 结果的文件数据默认勾选为实数（Real）类型。若需要和对数值（dB）的结果进行对比，我们可以在导入文件时选择对应的数据类型。

## 定义参考线

例如，我们想要对比的结果为 S 参数（图2.7），该结果的显示类型为对数（dB）。

和线性结果的参考线定义类似，我们可以用同样的方式定义以 dB 方式显示的参考线。

参考图2.7，我们要在 5.5-6 GHz 范围内添加纵轴坐标为 -5 dB 的参考线，只需要将第二列的数值定义为对应值（图2.8），然后保存即可。

## 导入参考线

在导入的时候选择正确的数据类型，就能够将此处的纵坐标数值与 dB 值对应上。

同样地，在 1D Result 中新建一个文件夹，导入要对比的 S 参数。右键点击该文件夹，选择 Import Result Curve From Ascii File（图2.9）。

在弹窗中选择对应的文件，并在下面的 Data Format 中选择 Magnitude dB 类型，随后点击"打开"，完成导入（图2.10）。

## 显示结果

导入完毕后，将导入的结果 Import1 重命名为 SP-Reference1。

点击该文件夹以显示文件夹下的所有结果，直观地查看仿真结果是否符合规范（图2.11）。

## 2c.对比S参数的相位（Phase）

在相位结果中添加参考线，流程和前面一样：确定参考线范围，编辑参考线并导入，选择对应的绘图类型。

## 定义参考曲线

将 S 参数结果以相位（Phase）的方式显示，我们希望在 8.6-9.6 GHz 范围内添加纵轴坐标为 -135 的参考线（图2.12）。

根据所需范围编写参考线的关键点（图2.13）。

## 导入参考曲线

同样地，在 1D Result 中新建一个文件夹，导入要对比的 S 参数。

在上文中，我们在 S 参数的 dB 绘图类型中添加了参考线，在这里我们要对比的数据类型为相位（Phase），出于演示的目的，我们新建一个文件夹，与 Magnitude dB 数据类型区分开来。

右键点击该文件夹，选择 Import Result Curve From Ascii File（图2.14）。

## 显示结果

导入完毕后，将导入的结果 Import1 重命名为 SP-Phase_Reference。

在 Plot Type 中选择 Phase，将绘图类型修改为相位（图2.16）。

点击该文件夹以显示文件夹下的所有结果，直观地查看仿真结果是否符合规范（图2.17）。

## 拓展：修改结果的数据类型

保证"原始数据"和"参考线"两个数据具有一致的数据格式，可以通过修改参考线的数据类型适应原始数据，也可以通过修改原始数据的类型适应参考线。

如果我们希望在 S 参数中添加参考线，导入时将数据类型错误地勾选为 Real 或者 Magnitude，会导致无法正确地显示参考线。

在导航树中点击该文件夹，以显示文件夹下所有的结果，我们可以看到：以 Magnitude 类型导入的参考线 SP-Reference2 没有显示在结果中（图3.1），因为参考线的数据类型（Magnitude）和 S 参数的数据类型（Magnitude dB）不一致。

可以考虑修改原始数据类型，将其数据格式从 1DC 转换为 1D，以适应参考线的结果类型。

修改数据类型的具体操作方法为：切换到 Post-Processing 功能区，点击 Result Templates（图3.2），在后处理模板对话框中选择对应的后处理模板（图3.3），按照实际需要对结果曲线进行数据转换。

## 总结

CST 内置了一些 EMC 标准的参考范围标注，用户可以通过调用 EMC Workflow 中的 EMI Standard Limitied Lines 功能进行操作。

对于通过 Import Result Curve From Ascii File 手动导入的参考线，可以直接编写参考线的关键数据点，导入的时候选择原始数据对应的数据类型，才能够在同一窗口中与原始数据对比。

如果需要修改数据类型，可以使用后处理任务转换，只有数据类型一致，才能够在同一窗口中显示。
