## 引言

在移动通信设备的研发、测试和认证过程中，设备在实际使用场景中的射频性能表现至关重要。设备被用户手握持时会不可避免地对手持状态下的无线信号传输（特别是毫米波）和天线性能产生显著影响，这一人体遮挡效应是设备设计的重要考量因素之一。

鉴于此，CST Studio Suite® 等 CAE 软件提供了 CTIA 手部模型导入的功能模块，以满足对手握电子设备进行电磁仿真的需求。基于 CST Studio Suite 2025 和 Bio Extension 4.5，本文将介绍导入手部模型的方法，分析各种手部姿态的具体应用场景，介绍自动握持手机的操作方法，并通过一个具体的案例带领读者实操。
## 一、CTIA 手部模型简介

CTIA 手部模型由 The Wireless Association®（美国无线通信和互联网协会）开发的标准手部模型用于握持不同手机类型，以满足认证测试需求。为移动设备厂商、认证实验室提供符合 CTIA OTA 测试规范的标准化手部模型解决方案，覆盖电磁仿真（CST）、辐射性能测试（TRP/TIS）、人体遮挡评估等场景，助力 5G/毫米波设备认证。

## 二、静态手部模型

静态手部模型仅可用于导入，这些手部模型可直接作为子项目导入已打开的CST工程，材料属性将自动设置为标准值。

静态手部模型无法修改手指弯曲的角度，且需要手动对齐手机模型。

模型中用于辅助定位的对齐垫片（spacers）被设为真空（Vaccum）材料属性。

静态手部模型可提供五种握姿：

- 宽握式（Wide Grip）
- 平板式（PDA）
- 直板式（Monoblock）
- 折叠式（Fold）
- 窄握式（Narrow）

## 三、自动握持手部模型（姿态可调）

为便于手指贴合手机模型，CST提供适用于 宽握式（Wide Grip）、平板式（PDA）和直板式（Monoblock） 的VBA宏脚本（含左右手版本）。执行宏脚本会生成定义每根手指位置角度的参数（其中正角度表示张开手掌），手部自动闭合直至每根手指接触手机。

## 操作步骤

1. 放置局部工作坐标系（WCS）

    - 左手模型：置于手机 左下角
    - 右手模型：置于手机 右下角
    - u轴 指向手机右侧（双手通用，沿宽度方向）
    - v轴 指向手机顶部
    - w轴 指向手机 背面到正面的方向 （即朝向用户头部）

2. 框选 手机中需接触的部件（通常为手机外边框、外壳等结构）

3. 运行宏：Macros -> Bio Extension 4.x -> Hand Phantom

## 操作案例

体验自动握持功能并学习 WCS 定位

1. 打开 File -> Component Library  搜索 dummy；

2. 打开 Dummy Phone 72mm 工程文件；

3. 在导航树中选择 Components -> Phone（该工程已经自动创建好WCS）；

4. 运行宏：Macros -> Bio Extension 4.x -> Hand Phantom；

5. 在对话框中选择宽握式（Wide Grip）、可调姿态（Posable），根据需要选择左手（Left）或右手（Right）， 手部模型将自动加载并握持示例手机。

6. 点击 Parameter List 对话框，可以查看并修改手指弯曲的角度参数。

## 四、横屏握持（游戏模式）与通用可调手部模型

二者的图例可查阅 表1 中的 Generic 和 Landscape Grip 类别。

通用可调手部模型（Generic）：

- 可通过部件库或宏路径 Macros -> Bio Extension 4.x -> Hand Phantom 调用（适用于 Bio Extension 4.3+ 版本）。
- 按 CTIA OTA 测试规范尺寸创建，可通过参数列表（Parameter List）调整。

横屏握持手部模型（Landscape Grip）：

- 在宏对话框中作为自动握持类型提供；
- 左手横屏 WCS 定位示例见部件库中的 Dummy Phone 72mm 工程；
- 右手横屏握持的 WCS 定位与纵向握持（portrait orientation）相同。双手握持可以通过镜像复制实现。

## 总结

- CTIA 手部模型可使用 Marco 脚本和 Bio-Model 导入向导两种方式添加，并支持多种实现效果。
- 模型分为静态和自动握持两种类别，自动握持模型的姿态可以按需调整。
- 可以通过CST案例库中的Dummy Phone 72mm工程文件进行实际操作，直观查看不同类别手部模型的区别。
